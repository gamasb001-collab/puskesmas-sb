# Puskesmas Digital v2.0
Frontend statis (GitHub Pages) + Google Apps Script sebagai REST API. © Arraihan Academy — lihat LICENSE.txt.

- Mode terang/gelap (ikut sistem, bisa diganti, tersimpan)
- Akun demo 7 hari + halaman Aktivasi (kunci terikat ID Instalasi)
- Pendaftaran online idempoten, cache lokal, retry, deteksi offline
- Responsif: ponsel, tablet, desktop, layar lebar

Isi `js/config.js` (GAS_URL) sebelum di-push. Panduan lengkap: PANDUAN-INSTALASI.md.
